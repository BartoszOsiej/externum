Externum compiles to plain readable Python, standalone Bash (real functions, recursion, set -euo pipefail), or a source-less bytecode artifact. No runtime you have to ship — the backends are the runtimes your machine already has.

[01] WHY

WRITE IT ONCE.
RUN IT EVERYWHERE A SHELL LIVES.

# hello.ext — the same file powers all three targets def greet(name: Str) -> Str: return "Hello, " + name + "!" mut names: [Str] = ["world", "bash", "cpython"] for n in names: print(greet(n))

$ externum run hello.ext · $ externum compile --target bash hello.ext · $ externum vm hello.ext

[02] TARGETS

THREE BACKENDS.
ZERO NEW RUNTIMES.

Python

Readable, idiomatic CPython output — debug it with the normal tooling, ship it as source. ~1.6× slower than CPython on the honest bench.

TARGET: CPYTHON · DEBUGGABLE

Bash

Standalone strict-mode scripts: real functions, recursion, arithmetic that respects types. The compiler warns instead of silently emitting footguns.

TARGET: /BIN/BASH · ZERO_DEPS

Bytecode

A source-less artifact for the bundled VM — your logic ships without shipping the source. Same frontend, same semantics, own stack machine.

TARGET: EXTERNUM_VM · SOURCE-LESS

[04] STORY

THE BENCHMARK THAT
CAUGHT ITS OWN BUGS.

The honest benchmark found two silent VM bugs — then we shipped a differential harness that runs every program through all three backends. Its first morning on duty it caught three more, including the bash backend compiling add(2, 3) into "23" because "+" always meant concatenation. Our benchmark returned 0 instead of 499500. Silently. rc=0.

All five: root-caused, fixed same day, promoted to tier-1 consensus tests. Backend drift is now CI-enforced at zero.
